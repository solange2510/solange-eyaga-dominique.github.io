# Solange EYAGA NDEME — Cybersecurity Portfolio

Personal cybersecurity portfolio built with HTML, CSS and vanilla JavaScript.

## GitHub Pages

1. Upload `index.html`, `style.css`, `script.js` and the `assets` folder to the root of your repository.
2. Put your CV in `assets/CV-Solange-Eyaga.pdf`.
3. Open **Settings → Pages** in your repository.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select your main branch and `/ (root)`.
6. Save and wait for GitHub Pages to deploy.

## Personalize before publishing

In `index.html`, replace:
- `YOUR.EMAIL@example.com` with your professional email.
- `https://www.linkedin.com/` with your LinkedIn profile.
- `https://github.com/` with your GitHub profile.

You can also replace/add project links when the individual project repositories are ready.
